# RISC-V SoC 版本特性与迭代记录

本文档用于记录 RISC-V SoC 各大版本的演进历程与主要特性。

---

## 00_rv32i_basic（基础版）
> **修改时间**: 2026-05-18 | **作者**: Wang Jianghao | **版本状态**: 归档

此版本为简化的 RV32I + Zicsr 处理器 SoC 设计基础版本。
**主要特性**：
- 支持基础整数执行 (RV32I) 与 CSR 异常重定向 (Zicsr)。
- 包含简单的 SoC 总线、UART MMIO 外设。
- **存储模型**：ITCM 和 DTCM 均采用“组合逻辑读、同步写”（即所谓异步读，数据在地址给出的同一周期返回）的简化 RTL 模型。
- 流水线冒险控制基于此异步读模型，Load-use 检测及跳转刷新机制相对简单。

## 01_rv32i_sramtcm（当前迭代版）
> **修改时间**: 2026-06-27 19:45 | **作者**: Antigravity | **版本状态**: 当前迭代

本迭代主要致力于解决物理 SRAM/BRAM 宏模型适配及时序收敛问题，同时修复了测试中暴露的 Bug。
**主要更新内容**：
1. **SRAM 化存储时序重构**：
   - 将 ITCM 与 DTCM 访存行为全面更改为真实的“同步读、同步写”物理 SRAM 时序模型。
   - IFU 增加了流水级状态寄存器，拆分了 Request PC 和 Response PC，实现了取指请求与取指数据的 Pipeline 一拍对齐。
   - DTCM 读写请求提前至 EXU 级，在不破坏现有 Load-use 停顿（仅 stall 一拍）和数据前递策略的前提下，实现了数据存取的同步化。
2. **修复 Zicsr 兼容性测试超时问题**：
   - 在 RTL 核心（`csr_regs.sv`）中补全了 `mscratch` 暂存寄存器的读写支持，修复了因缺失该硬件设施导致异常处理陷入死循环的问题。
   - 改进了 Testbench（`tb_soctop_isatest.sv`）的异常截获机制，通过监听针对 `tohost` 端口的异常写入，可在遇到报错死锁时立刻终止仿真（提前退出），大幅提高了 debug 效率。
